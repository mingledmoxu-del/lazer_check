# v3.9.6 连续圆周测试上位机

解压 `upper-computer-sdk-source.zip`，运行 `app/start_simple.bat`。**沿用已有 H743 v3.9.4 固件，无需改固件或重新烧录。** 本包不含新固件，原SDK接口兼容。

主界面进入「风扇几何 / 连续圆周测试」，输入模型或实机的直径、跟踪半径、转速、距离、两者高度、横向偏移、叶轮平面倾角和原点。按「生成预览 → 定位起点 → 上传（不运动） → 单独启动」测试，连续运行有限圈数，中途不逐点停车。默认台架数据需按真实安装核验；切换实机后关键几何清空，必须实测填写。

一次最多128个带时间的角度点，完整预上传到独立的连续轨迹缓存，不覆盖六套逐点库。固定时间执行，含可配置渐入/渐出；当前没有真实叶轮相位反馈，不自动锁定同一真实叶片，不启动激光采集。

提供理想圆与角度反馈投影图、跟随误差/控制周期/阶段耗时，导出JSON、反馈CSV和计划轨迹CSV。编码器投影不等于实测光斑，物理抖动需要目测评级或外部测量。

详细说明：[风扇几何与连续圆周测试](../../../docs/v3.9.6_风扇几何与连续圆周测试.md)，源码包内 `docs/` 也包含文档。
