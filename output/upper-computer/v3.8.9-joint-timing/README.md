# v3.8.9 两轴联动往返计时

上位机新增调试窗口，继续使用 v3.8.7 固件和现有 SDK。无需重新烧录。此功能不建立、不清除参考，也不修改驱动器参数。

## 操作流程

1. 连接网口，完成电机1参考建立及电机2参考确认，停止其他动作。
2. 点击主窗口的「两轴联动往返计时（10°→0°→10°）」。无需展开高级调试。
3. 每行输入一个两轴目标，第一列是电机1角度，第二列是电机2角度；例如：

   ```text
   10,10
   0,0
   10,10
   ```

4. 设置速度、循环次数，点击「开始联动计时」并确认。两轴从实际当前位置开始第一段，两轴都完成后才执行下一段。
5. 点击「导出CSV」保存表格。日志窗口同时输出 `JOINT_TIMING`；原有 `TIMING` 阶段日志仍写入 `app/logs/motion_timing.jsonl`。

速度沿用复位界面的设定规则：0.2～1.5，默认0.6，实际输出轴rpm=数值÷6。例如0.6对应0.1rpm、0.6°/秒。线上0x19速度以0.01rpm分辨率量化。循环范围1～100；目标表最多100行。电机1目标范围−29°～+35°；板端仍执行实际限位及软范围保护。

## 联动与计时口径

每段依次下发两条0x19定位命令，然后通过0x37/0x4652直接读取两轴实际反馈。两轴可同时运动，但当前协议每次发送一条轴命令，不能保证同一时刻启动、同步到达或轨迹插补。表格记录两次实际下发的间隔，避免把通信间隔误认为机械差异。

表格每段两行，每轴一行，全部时间单位为秒：

| 界面 / CSV字段 | 含义 |
|---|---|
| 段 / step；轴 / axis；目标° / target | 本次段号、轴号、绝对参考角度 |
| 准备 / prep | 本段开始到该轴指令下发 |
| 应答 / ack | 该轴下发到STM32接受应答 |
| 启动 / start | 该轴下发到首次观察到非零转速；未观察到则留空 |
| 到位 / window | 该轴下发到首次进入目标±0.5° |
| 到位→停稳 / settle | 首次进入±0.5°到确认完成 |
| 轴总耗时 / total | 本段开始到该轴确认完成 |
| 联动总耗时 / joint_total | 本段开始到两轴均确认完成，两行数值相同 |
| 下发间隔 / skew | 两轴指令下发时间差；某轴无需运动则留空 |
| 结果 / result | 完成、无需运动，或者停止/失败原因 |

完成要求：参考有效、两轴直接反馈来源0、样本年龄≤200ms、无驱动报警或保护故障；对应轴角度在目标±0.1°内，转速为0、无运行/停机待确认标记，并有固件0x40完成标记。该标记代表板端连续两次独立零速确认，不使用单次零速代替停稳。已经在目标±0.001°内的轴记为「已在目标，无需运动」，不伪造启动和下发时间。

窗口状态显示整次测试总耗时，包含初始检查、段间查询。表格时间是主机观察时间，包含网口及RS485查询延迟，不能视为驱动器内部精确时刻；轮询至少间隔50ms，实际采样周期取决于两轴读取耗时。

## 停止与异常

窗口或主界面「停止」均取消后续所有段，依次停止两轴，并通过两次直接反馈确认停稳。关闭窗口也取消测试；不会关闭运动中的流程后继续自动换点。断线时尽力向两轴发送停止，但不声称已停稳。

参考失效、报警、命令拒绝、读回失败或超时会取消后续段并请求两轴停止。没有完成的阶段留空并记录原因，不计作成功。测试期间阻止其他定位、复位、配置动作；不会自动清故障、重建参考或重发失败定位。
