# v3.9.5 模拟叶片跟随测试上位机

下载并解压 `upper-computer-sdk-source.zip`，运行 `app/start_simple.bat`。继续配套 **v3.9.4 H743固件**，无需重烧；本包不含新固件，SDK业务接口保持v3.9.4。

主窗口点击「模拟叶片经过 / 三点四点跟随测试」，选择P圈、三/四点、模拟每转时间、实际输出轴rpm及几何参数。核对真实参考后，先预载并定位起点，再点击开始模拟。默认台架2.5m几何与原点须按实际安装核验，测试占用并覆盖板端库6。

测试会实际驱动电机，不启动激光采集。导出每段发令、应答、首次运动、到位、停稳、模拟叶片到达、赶点余量、编码器波动及人工抖动评级；CSV和同名JSON配套保存。抖动评级需要人工填写，编码器角度不代表机头/光斑物理稳定。

详细操作及字段：[模拟叶片经过与跟随测试](../../../docs/v3.9.5_模拟叶片经过与跟随测试.md)。压缩包内 `docs/` 同样包含文档。

已通过250项Python测试及Tk窗口构造检查；没有连接电机或运行实物路线。新功能的赶点能力、负载抖动须实机验证。
