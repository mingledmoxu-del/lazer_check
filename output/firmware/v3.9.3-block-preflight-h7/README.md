# v3.9.3 减少应答准备与日志阻塞

H743主工程：烧录本目录 `LightCheck.hex`（起始0x08000000），解压 `upper-computer-sdk-source.zip` 并运行 `app/start_simple.bat`。需同步更新固件和上位机，不能仅换界面获得板端优化。

本版将每轴准备参数合并为两个当前读取块，并去掉同一次定位指令前重复的空闲保护查询；对不支持块读取的驱动器按明确异常回退。限位、当前位置/目标范围、参考、报警和实际双零完成核验保留，未用旧参数缓存替代实读。

上位机日志改为50ms批量显示、最多保留2000行，详细运动计时JSONL继续保留；修正同包两轴的计时偏差。CSV导出修复新增字段漏同步导致的只有表头问题。

联动/预载页速度仍为真实输出轴rpm，0.01～100，默认0.1；终点容差默认±0.2°。修改预载速度后重新上传。API与v3.9.2兼容；复位窗口仍按其自身速度规则。

219项Python、15组C、H743 Debug构建及Tk界面/2050行日志批处理检查通过。未进行本版实机运动，不能保证应答或完整动作固定在某个时间内。
