# v3.9.1 固定点位预载与±0.2°完成容差

同时烧录本目录 LightCheck.hex（起始地址0x08000000），解压 upper-computer-sdk-source.zip 并运行 app/start_simple.bat。不要混用旧固件与新SDK。

完成两轴参考建立并停稳后，主窗口进入「两轴联动计时 / 预载固定点位」：选择四点测量路线，库编号1，按需设置速度（实际rpm=数值÷6），终点容差默认0.2°，点击「提前上传点位（不运动）」。选择点0～5并运行，每次只运行所选点，停稳后等下一条指令。点5为返回(0,0)，不是重新标定。

支持4套RAM库，每库16点，断电/复位或参考变化后需要重新预载。SDK推荐一次 preload_route()，再在业务事件中调用 move_preloaded_point_and_wait()；返回完成快照及accepted_ms/wait_ms/elapsed_ms，避免业务层重复停止和全量核验。

±0.2°策略仍要求两次实际零速及直接最终位置核验，保留限位、报警、参考和通信检查。本版已通过213项Python测试、14组主机C测试、Tk界面/库切换及H743构建；未进行本版实机测试，时间收益待同条件复测。

完整接口、协议、速度及容差口径见源码包 docs/v3.9.1_预载点位与0.2度完成容差.md。旧v3.9.0发布包保留用于对照。
