# v3.9.0 配套固件与上位机/SDK

请烧录本目录 LightCheck.hex（起始地址0x08000000），解压 upper-computer-sdk-source.zip 后运行 app/start_simple.bat。需要一起更新固件和上位机/SDK。板子复位后按原流程重新建立两轴参考。

主窗口进入两轴联动往返计时，沿用原速度和10°→0°→10°目标进行对比，完成后读取板端耗时。

已通过205项Python测试、13组C测试、H743编译及GUI构造检查；尚未进行实机性能验证。实际时间收益需同条件测试，不以ACK代替完成。

详细更新、协议和同事API接入说明见源码包 docs/v3.9.0_降低定位通信与停稳额外耗时.md。旧版本v3.8.7固件保留在相邻发布目录，可作对照。
