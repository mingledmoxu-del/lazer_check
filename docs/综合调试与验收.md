# v2.0综合调试、扩展接线和验收

> v2.1覆盖说明：电机1固定采用水平0°、传感器参考+25°、软范围−35°～+35°；回零成功或人工捕获参考后自动启用软范围。电机2保持下文相对坐标。下文“参考位置为0°”仅适用于电机2；电机1人工参考须在+25°姿态建立。完整变更、接口语义和实测注意事项见上位机README的v2.1章节。

当前目标：两轴各一个EE-SX674-WR，允许以后扩展到每轴负限位、正限位、原点三个逻辑角色。
所有运动、回零、软限位仍是普通控制功能，不是安全级急停。必须保留独立硬件急停；配置和运动试验都应有人看护。

## 1. 位置反馈原理与单位

P100S自身读取电机编码器，STM32通过Modbus RTU读取驱动器的监视寄存器：

| 地址 | 数据 |
| --- | --- |
| 0x1000 | 有符号电机rpm |
| 0x1001、0x1002 | 实际位置低16位、高16位 |
| 0x1003、0x1004 | 指令位置低16位、高16位 |
| 0x1005、0x1006 | 位置偏差低16位、高16位 |

低/高字合成有符号32位。必须结合P3-32解释：0/1按编码器分辨率显示，2/3按PA11指令分辨率显示；0/2为增量显示，1/3为绝对显示。PA95是编码器分辨率指数（如17→131072），不是PA11。
本项目建立软件零点前，在停稳状态将P3-32设为3并读回验证，然后保存反馈偏移。只改变监视数据单位，不写PA95，不清P3-34编码器多圈数据，不修改SON接线。

同一显示单位下：

```text
反馈净位移 = 本次实际计数 - 参考实际计数
输出轴净位移角度 = 反馈净位移 / 每电机圈反馈计数 / 减速比 × 360°
P3-32=3时，每电机圈反馈计数 = PA11；当前减速比=50:1
```

软件角度只有在零点有效且单位未变时才提供，否则显示“未建立/已失效”，API返回None。
先做可视标记的小角度试验核对计数是否连续、与机械运动是否匹配。不能把单圈角度、减速器输出角度、指令脉冲、编码器原始分辨率混用；计数回绕/驱动器重启/单位改变后须重新检查并建立参考。

## 2. 输入预留与接线

原理图确认DI0～DI5对应PF5～PF0，均位于J7的ICOM1输入组。MCU不直接接24V。

| 逻辑建议（可在界面重映射） | 板子丝印 | J7针号 |
| --- | --- | --- |
| 电机1当前原点 | DI0 | 9 |
| 电机2当前原点 | DI1 | 8 |
| 预留电机1负限位 | DI2 | 7 |
| 预留电机1正限位 | DI3 | 6 |
| 预留电机2负限位 | DI4 | 5 |
| 预留电机2正限位 | DI5 | 4 |
| 共用输入供电端 | ICOM1→外部+24V | 1 |

EE-SX674-WR是NPN型号。传感器供电和ICOM1必须构成完整回路。原厂常见线色为棕Vcc、蓝0V、黑输出、粉L；实物若为白线替代粉线，必须依据该实物接线图确认其是否为L，不靠线色猜接。
当确认L接Vcc选择Light-ON时，未遮光输出导通，板子GPIO为低；遮光/输出线断开/失电为高。因此界面默认“高电平触发”。若使用不同模式，必须先做遮挡、解除、断线三种测试，再选电平，不能用翻转逻辑绕过接线故障。

角色解释：

- 负/正限位：触发时锁存停止请求；停稳后只允许向离开对应端点的方向发新动作。
- 原点在端点：填写固定回零方向并确认后，可作为该端点的方向约束；也可将同一通道同时映射为原点及对应负/正限位。
- 原点在中间：仅作为回零参考，不把每次经过原点都当成硬限位；正常运动应依靠软范围及另外的正负限位。一个中间原点不等于双端保护。
- 同轴原点与一个端点可共用；正负限位不能同通道，两轴启用的输入不能共用。未安装通道设为未使用。

输入每1ms采样，触发锁存，解除连续稳定30ms。ISR只采样，不发送串口、不执行驱动器通信。实际停止延迟取决于主循环、RS485、超时和机械减速，绝非1ms停止保证。

## 3. 软件坐标、范围和运行策略

- 默认只采样，不启用硬/软策略，不自动运动或回零。
- 每轴配置、软件零点仅在RAM；MCU重启、重新烧录后读取状态并重新确认。不要沿用旧界面值或JSON里的“已回零”。
- “人工当前位置为零”不是找到机械原点；会改变物理软界限的基准，必须人工确认。
- 软范围必须包含零点，允许范围为-36000～36000°。启用前需要有效零点，当前角度必须在范围内。
- STM32在动作前检查目标，动作中轮询实际位置，越界/反馈失效/通信失败时请求停止。范围不能贴着机械硬止挡，须预留停止距离。
- 软范围启用时拒绝无终点连续速度、原始绝对位置、通用PA写入和旧速度命令，避免绕开保护；用输出轴相对运动或软件坐标定位。
- 正常原始读取、停止、报警查询仍可用。加减速不可在连续旋转/回零中直接修改；先停止。
- 短输入脉冲即使在通信阻塞期间解除，也不会被当成从未触发。停机失败保持拦截并重试；不会自动续跑旧命令。
- 配置分步执行，失败不回滚此前已成功的独立步骤；以读取下位机实际配置为准。

## 4. 回零状态机

启动前必须：输入映射已应用、硬输入策略已启用、方向/安全侧人工确认、原点输入未触发、其他限位正常、电机已停稳且无报警。
原点初始触发既可能是真实位置也可能断线，所以禁止上电盲目反向退出。先人工检查，必要时沿已确认安全方向低速退开，再重新开始。

流程：寻找原点→触发后停止并连续确认零速→反向退出直到输入稳定解除→停止确认→以更低速度重新接近→再次触发后停止确认→将最终停车位置设为软件零点。

参数：

- 搜索速度：最大5°/秒，受整数电机rpm取整影响；建议从默认0.5°/秒开始。
- 总行程预算：最大360°，包含寻找、退让、二次接近的累计反馈路程，不只是单向搜索距离。
- 最大退让：最大10°，且不能超过总预算；默认2°。退出不了则失败，不把一直触发当作原点成功。
- 总超时：1～120秒，默认90秒。低速、长行程可能先超时，须按实际范围合理设置。
- 移动阶段约3秒无反馈变化、明显反向计数、非原点限位触发、反馈单位变化、通信/驱动报警、预算耗尽都会失败。
- 上位机或API每约1秒心跳；超过5秒未续期，下位机请求停止。迟到心跳不能重新启动；人工停止也取消整个状态机。

回零失败会使零点无效，禁止继续用旧软件坐标。输入故障仍可能模拟真实边沿，双次接近只是提高诊断能力，不是安全认证。最终零点是停车位置，不是硬件锁存边沿，需测重复精度和回差。

## 5. 推荐验收顺序

1. 电机不使能：读DI0～5，遮挡/解除/拔开输出线，验证触发电平与通道一一对应。
2. 无自动回零：低速小角度核实两轴正方向、50:1及实际反馈计数单位；记录CSV。
3. 人工置零：确认当前位置基准，读取有效角度；设一个远离机械端点的小软范围，启用后验证范围内动作允许、范围外命令被拒绝。
4. 验证停机：遮挡对应负/正限位，确认只停止对应轴；试向端点移动应拒绝，停稳后向离开端点方向小角度运动应允许。
5. 原点回零：逐项确认安装位置/接近侧/方向，采用很小的预算、低速、独立急停，首次全过程看护。
6. 异常试验：先在安全位置验证人工停止、原点初始触发拒绝、退出失败、搜索预算、断线/心跳丢失；确认均不自动重启、不生成有效零点。
7. 完成回零后启用实际软范围，重复同一目标多次，对比机械角度、位置偏差和零点重复性。不要只看成功回包或0rpm。

## 6. 新协议摘要

| 命令 | 请求/响应 |
| --- | --- |
| 0x20读取反馈 | 无请求数据；响应34B：实际i32、指令i32、偏差i32、模式u16、PA11u16、PA95u16、软件毫度i32、flagsu16、rawDIu8、activeDIu8、phaseu8、faultu8、origin i32、rpm i16 |
| 0x21配置 | parameter=1：负/正/原点通道+高电平触发，4B；parameter=2：最小/最大毫度，8B；parameter=3：策略位和有符号方向，2B |
| 0x22人工零点 | parameter=0x5A52，无数据；停稳、设置并验证P3-32=3，记录软件偏移 |
| 0x23启动回零 | parameter=0x484D，4个i32：毫度/秒、总行程毫度、退让毫度、总超时ms |
| 0x24读取配置 | 无数据；响应17B，见Python GuardConfig解析 |

多字节字段均大端（CRC除外）。反馈flags：bit0零点有效、bit1软范围启用、bit2硬输入启用、bit3方向已确认、bit4停机待确认。
策略位：bit0硬输入、bit1软范围、bit2方向确认、bit3原点位于端点；方向-1/0/+1。通道255代表未使用。
phase：0未开始、1寻找、2触发停稳、3退让、4退让停稳、5慢速接近、6最终停稳、7成功、8失败。
fault：0无、1传感器/退出失败、2预算/范围、3反馈、4超时/心跳、5通信、6驱动报警、7人工取消。
状态0x09表示范围/不允许绕过保护，0x0A表示未建立参考或未确认配置。无需直接操作原始寄存器，优先调用app公开API。
