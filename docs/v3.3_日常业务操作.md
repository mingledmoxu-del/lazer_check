# v3.3 日常业务：参考 → 水平0° → 两轴运动

> 当前v3.4保留本文的准备流程，并允许日常API覆盖速度/加速度默认值，新增轨迹故障确认清除。加速度3不是最大值，故障恢复见[v3.4说明](v3.4_加速度与轨迹故障恢复.md)。

需要本版上位机/API和配套新固件。驱动总线保持115200/8N2，两台驱动器PA72=1152、PA73=0保存复位；PC串口仍115200/8N1。没有自动使能SON、改通信参数或猜测机械姿态。

## 操作人员只需这几步

1. 人工将电机1摆到真实抬头+25°，点击主窗口“① 确认电机1当前为+25°”。程序停止该轴、连续两次确认零速，再让STM32记录该位置对应+25°并读回核实。此步只确认参考，不自动定位。
2. 点击“② 电机1移到水平0°”。程序读取当前可信角度，按0.1输出轴rpm移到水平0°。连续读到两次实际角度在±0.3°内且零速后才认定停稳；不会只凭运动应答宣称到位。
3. 每次STM32/驱动器掉电导致参考失效后，将电机2放在所需业务0°，点击“电机2：确认当前位置为0°”。电机2参考仍必需，默认不启用角度范围，不用填写软限位。参考已有效时，无需每次业务前重新置零。
4. 主窗口持续显示两轴实际位置；两轴参考有效、零速、无报警或保护处理中，且电机1在水平0°时，连续两次反馈后显示“业务就绪”。点击“③ 两轴业务轨迹”进入业务。
5. 可以导入同事生成的轨迹，或生成默认关节角示例。日常示例从实际当前位置开始并回到同一位置，不再要求手动移到一个额外首点：电机1相对当前±5°，电机2相对当前0～+10°，计划约20秒（自动减速可延长）。它是关节角空间的闭合曲线，不是机构标定后的末端空间圆。
6. 点击上传校验，再明确启动。导入轨迹的首点仍须与实际位置一致；软件不会猜测到业务首点的机械路径。停止始终可用，会取消参考／定位流程里尚未发送的动作。

未连接、位置过期、参考无效、仍在运动或有故障时不会显示业务就绪。运行和停止确认期间使用下位机控制缓存，停止后重新读取驱动器；超过2秒未更新会撤销日常就绪。断开连接、通信超时或操作停止会取消待发准备步骤，迟到回复不会自动触发定位。失联时运动状态仍须由现场核查，通信停止不是硬件急停。

## 电机1固定保护，电机2可无范围

- 电机1机械坐标：水平0°、人工参考+25°，范围固定−35°～+35°。未建立可信参考时下位机拒绝普通运动。参考建立后不允许关闭保护，也不允许通过范围命令扩大或缩小；日常界面不再配置这些参数。
- 电机2默认没有角度范围。轨迹仍检查可信参考、反馈换算、实际速度、驱动报警、通信和已启用的硬输入策略；不再因为没开启软范围而拒绝两轴轨迹。若高级配置主动开启了电机2软范围，仍按该范围保护，不会自动关闭。
- 不设电机2角度范围的前提是机构与线缆允许所需运动。参考无效不能假装成0°，也不能靠反复置零消除错误。

## 调试参数放在高级入口

主窗口原定角、速度、参数、传感器配置默认折叠；轨迹窗口的阈值、周期等默认折叠。日常上传使用统一预设：100ms控制周期、最大1.5°/s、最大3°/s²、最大跟随误差0.75°、起终点容差0.3°、两轴共同减速。

程序保留轨迹角度和顺序，必要时统一延长所有点的时间，以满足速度、加速度预设；运行时任一轴落后，两轴共享的路径进度一起放慢。严重误差、参考异常、失联、限位和推进超时仍然停机，不是关闭保护。实际运行时间可能延长，不能承诺固定圈时、精确末端圆或无故障。总时长超过协议600秒的轨迹仍须重新规划。

## 同事API的简化调用

人工在GUI建立的参考保存在STM32，两边共用，不需要API再置零。保持使用同一参考；不要GUI和业务程序同时抢占同一个PC串口。

```python
# 只在人工确认真实姿态且需要重新建立参考时调用：
motors.set_current_reference(1)  # 当前真实姿态必须是+25°，此调用不移到水平
motors.set_current_reference(2)  # 当前真实位置定义为电机2业务0°

# 单独、明确地请求电机1到水平，并等待实际到位/停稳：
motors.move_axis1_to_horizontal()

# points是输出轴角度轨迹，首点与两轴实际位置一致。
# 使用固定日常预设，自动延长过快轨迹时间；只预载，不启动。
ready = motors.prepare_business_trajectory(points)
motors.start_trajectory(ready.session)
motors.wait_trajectory(ready.session)

for axis, position in enumerate(motors.get_axis_positions(), 1):
    print(axis, position.angle_deg, position.sample_age_ms, position.usable)
```

`prepare_trajectory`仍保留给高级集成，旧接口不会自动改为日常预设；同事正常业务请使用`prepare_business_trajectory`。故障后的回首点预载沿用v3.2流程，本版允许电机2无软范围，但两轴参考仍须有效。故障后先看真实停稳位置与原因，不自动恢复旧会话。
