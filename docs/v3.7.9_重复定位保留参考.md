# v3.7.9 重复定位保留角度参考

本次仅修改上位机，继续使用 v3.7.7 固件，无需重烧。

此前“复位到35°”按钮每次都下发双限位配置，而固件配置命令会清除旧坐标参考；所以再次搜索中途停止后，就不能继续按角度定位。现在按钮改名为“回到+35° / 建立参考”，统一遵循以下流程：

1. 先停止并确认零速，再从板端读取当前反馈与参考有效位，不依赖上位机缓存。
2. 有有效参考且无保护故障：直接计算当前角度到+35°的差值，使用普通坐标运动命令。不会重新配置、搜索或清零，停止时保留原有参考。已在+35°附近（0.05°内）则不运动。
3. 没有参考：才下发实测双限位配置，再反向搜索DI0，停稳标定+35°。首次搜索在触发前取消，仍没有可用参考。
4. 读取失败、未停稳或有有效参考但存在保护故障：取消后续动作，不转入自动重新标定。停止也会取消正在等待的参考检查，迟到反馈不能启动搜索。

两种运动都使用复位窗口所选0.5/0.6/0.8/1.0°/秒。回到水平0°仍为独立按钮。断开重连不会自动重新下发配置；只要板端参考仍有效，再次定位就继续沿用它。

板子掉电/复位、重新配置限位、明确重新标定或编码器反馈单位异常仍可能使参考失效。本次保证普通停止和重复点击定位不主动丢弃有效参考，不把原本已失效的坐标强行标成有效。

验证：162项Python测试、10组C测试及GUI分支检查。覆盖首次搜索、已有0°/10°/35°附近参考的直接定位、配置失败取消后续搜索、停止取消待执行任务，以及固件普通停止保留既有参考。未执行现场运动。
