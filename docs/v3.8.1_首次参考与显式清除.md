# v3.8.1 首次参考建立与显式清除

现场截图为首次建参考，零速、坐标无效，却出现反馈单位错误及停机待确认。根因是固件READ_FEEDBACK将AxisGuard_Angle在“尚无参考”时的正常失败也当成了“已有参考丢失”，每次刷新都请求停机，上位机检查到停止待确认后取消了首次搜索。

本版仅在原本zero_valid=1且角度换算失败时报告反馈错误并停机。上电、主动清参考后的zero_valid=0是正常未标定状态，读取反馈不产生该错误；真实反馈单位变化的保护仍然保留。

GUI新增“清除电机1参考”按钮：确认后先停稳，再清除电机1坐标参考和旧轨迹，不自动搜索或定位。随后可点击“回到+35° / 建立参考”重新标定。SDK为`clear_axis1_reference()`，返回无参考的PositionFeedback。普通回35°和普通停止仍保留有效参考，不需每次清除。首次上电没有参考，也不需要先点击清除。

请同步更新v3.8.1固件及上位机。旧固件的重复停机不能仅靠清参考按钮解决。固件：`output/firmware/v3.8.1-first-reference-h7/LightCheck.hex`。

验证：173项Python测试、10组C测试、H743网口编译及GUI清参考流程检查。C回归覆盖未建参考且软范围已启用时连续读取反馈不产生故障或停止待确认；既有单位变化保护仍通过。新增API测试确认清参考不发搜索或定位命令。待实机验证。
