# v3.5：设置当前已知角度、读取实际角度

本版新增`set_current_angle`、`get_current_angle`，并允许`set_current_reference`显式传入参考角度。需要配套v3.5 STM32固件；驱动总线仍115200/8N2，PC串口仍115200/8N1，不改驱动器保存的上电配置或SON。

## 手动摆到0°后建立坐标

```python
from app import MotorController

motors = MotorController("COM7").connect()

# 人工已经将电机1摆到真实水平0°并停稳；电机2处于所需业务零点。
motors.set_current_angle(1, 0.0)
motors.set_current_angle(2, 0.0)

# 后续运动期间/完成后，均可以读取实际输出轴角度。
angle1 = motors.get_current_angle(1)
angle2 = motors.get_current_angle(2)
print(angle1, angle2)

# 结束控制时主动停止并关闭串口：motors.close()
```

设置参考会先请求停止并确认零速，再记录编码器位置对应所给角度，最后读回校验；不会自动定位到其他位置，不清编码器硬件多圈数据。它是坐标捕获操作，不是“让电机走到这个角度”的命令。

零点对应关系记录在STM32：`当前输出角度 = 参考角度 + 编码器实际位移换算角度`。上位机、API和下位机共用这套坐标，不需要各自累加指令。实际正向5°、再正向10°、再反向3°，应读取约12°；只接受了运动指令但电机没走，实际角度不会凭空增加。电机2角度保留多圈累计值，不按360°取余。

## 接口

| API | 含义 |
|---|---|
| `set_current_angle(id, angle_deg=0)` | 把当前停稳的已知姿态定义为指定角度，返回`PositionFeedback` |
| `set_current_reference(id, angle_deg=0)` | 显式传角度时与上一个接口等价 |
| `get_current_angle(id)` | 返回当前实际输出角度float；参考无效、读失败或反馈过期时抛`MotorError` |
| `get_axis_positions()` | 同时读取两轴角度、转速、采样年龄、参考有效性，适合界面持续刷新 |

所有角度都是50:1减速器输出轴的度数，不是电机转子角度；读取有通信/缓存延迟。轨迹运行中复用控制反馈，停机后重新读驱动器。`get_current_angle`只接受有效且年龄≤1000ms的数据，不会把未知位置当作0°；需要判断年龄与来源时用`get_axis_positions`。

### 兼容已有+25°操作

```python
motors.set_current_reference(1)             # 旧调用保持：真实姿态必须是+25°
motors.set_current_reference(1, angle_deg=0) # 新调用：真实姿态必须是水平0°
motors.set_current_reference(2)             # 旧调用保持：当前位置定义为0°
motors.set_current_angle(2, 12.5)           # 当前姿态已经被人工确认是业务+12.5°
```

旧`set_current_zero(1)`仍是兼容名称，含义是捕获电机1的+25°参考，不能当作水平0°设置。想在水平处直接置0，请使用`set_current_angle(1,0)`。

## 保护与生命周期

- 电机1仍固定−35°～+35°，参考角度只能在此范围内且须对应真实水平坐标。不能把任意倾斜姿态定义成0°再沿用该保护范围，否则物理边界关系会错误。
- 固定范围策略与“参考角度是否为0”分开存储，捕获0°不会关闭保护。电机2建立非零参考也不会因此变成固定范围轴；默认不启用角度范围，若高级配置已启用范围仍会校验。
- 成功改变任一参考会作废已缓冲的旧轨迹/会话。需要用新坐标重新准备轨迹，不会自动继续旧目标。
- 参考存在STM32 RAM，重启/掉电后应重新确认；不能假定上次业务零点自动恢复。检测到驱动器通信丢失、反馈单位或计数失效时，会撤销参考有效性，不自动重新认可旧零点。
- 传感器回零仍按传感器的物理基准建立坐标：电机1成功回零为+25°，电机2为0°，不会沿用上一次手动捕获的任意参考值。
- 该API不能代替机械标定或消除驱动器接SON自转；自转时先停机、处理保存的控制配置，不要带着旋转去捕获参考。

## 协议与验证

新增0x25，设备为目标轴，parameter=0x5246，4字节大端int32输出毫度；成功回包4字节回显接受的角度。固件停止后检查两次零速、反馈单位和报警，成功才捕获参考。旧固件拒绝时API不会自动退回+25°旧命令。
