## 1.1 通讯硬件接口

伺服驱动器具有 RS-485 串行通讯功能，使用 MODBUS 协议可实现：

- 伺服系统参数变更
- 伺服系统状态监视
- 其他通讯控制功能

## 1.2 通讯参数

### PA-71：驱动器 ID 号

| 参数 | 名称 | 范围 | 缺省值 |
|---|---|---:|---:|
| PA-71 | 驱动器 ID 号 | `1~254` | `1` |

使用 RS-485 通讯时，每台伺服驱动器应设置不同的站号。站号就是该驱动器在通讯网络中的绝对地址；如果多个驱动器设置了相同站号，会导致通讯异常。

### PA-72：MODBUS 通讯波特率

| 参数 | 名称 | 范围 | 缺省值 |
|---|---|---:|---:|
| PA-72 | MODBUS 通讯波特率 | `48~1152 × 100` | `96` |

参数值 `96 × 100` 对应波特率 `9600`。驱动器波特率必须与上位控制器一致。

### PA-73：MODBUS 通讯协议选择

| 参数 | 名称 | 范围 | 缺省值 |
|---|---|---:|---:|
| PA-73 | MODBUS 通讯协议选择 | `0~2` | `0` |

| PA-73 值 | 串口格式 |
|---:|---|
| `0` | `8,N,2`（MODBUS RTU） |
| `1` | `8,E,1`（MODBUS RTU） |
| `2` | `8,O,1`（MODBUS RTU） |

- `8`：8 位数据位。
- `N`：无奇偶校验；`E`：偶校验；`O`：奇校验。
- 最后的 `1/2`：停止位数量。

默认通讯配置为：`9600 baud, 8N2, Modbus RTU`。

## 1.3 MODBUS 通讯协议

通讯使用 MODBUS RTU 模式。每台伺服驱动器必须预先设置站号，上位控制器根据站号与对应驱动器通讯。

### 编码器意义

每个 8-bit 数据由两个 4-bit 的十六进制字符组成。例如：`64H` 表示一个 byte 数据。

### 字符结构

默认 `8,N,2` 格式：

```text
起始位 + 8 位数据 + 停止位
```

### 通讯数据结构

```text
STX | ADR | CMD | DATA(0) ... DATA(n-1) | CRC | End1
```

| 字段 | 含义 |
|---|---|
| STX | 与上一帧的时间间隔至少为 3.5 个字符时间 |
| ADR | 通讯地址，1 byte，范围 `1~254` |
| CMD | 命令码，1 byte |
| DATA | 数据内容，`N word = 2N byte`，`N <= 100` |
| CRC | 校验码，2 byte |
| End1 | 与下一帧的时间间隔至少为 3.5 个字符时间 |

### ADR：通讯地址

合法通讯地址范围为 `1~254`。例如与站号为 16（十六进制 `0x10`）的驱动器通讯：

```text
ADR = 0x10
```

### CMD：命令码

#### 功能码 `0x03`：读取 N 个 16-bit 字

请求帧：

```text
[ADR] [03] [起始地址 High] [起始地址 Low] [数据数量 High] [数据数量 Low] [CRC Low] [CRC High]
```

响应帧：

```text
[ADR] [03] [字节数] [数据 High] [数据 Low] ... [CRC Low] [CRC High]
```

示例：从站 `0x01`，从 5 号参数开始连续读取 2 个参数。

请求：

```text
ADR        01H
CMD        03H
起始地址    00H 05H
数据数量    00H 02H
CRC        D4H 0AH
```

响应：

```text
ADR        01H
CMD        03H
字节数      04H
5 号参数    00H 96H
6 号参数    00H 4BH
CRC        5AH 28H
```

#### 功能码 `0x06`：写入 1 个参数

请求/正常响应格式：

```text
[ADR] [06] [地址 High] [地址 Low] [数据 High] [数据 Low] [CRC Low] [CRC High]
```

示例：向站号 `0x01` 驱动器的 5 号参数写入十进制 `100`，即十六进制 `0x0064`：

```text
ADR        01H
CMD        06H
起始地址    00H 05H
数据内容    00H 64H
CRC        98H 20H
```

完整发送帧：

```text
01 06 00 05 00 64 98 20
```

### CRC 帧校验计算

1. 初始化 16-bit CRC 寄存器为 `0xFFFF`。
2. 将命令信息的当前字节与 CRC 寄存器低字节异或。
3. 检查 CRC 寄存器最低位：
   - 为 `0`：CRC 右移一位。
   - 为 `1`：CRC 右移一位，再与 `0xA001` 异或。
4. 重复步骤 3 共 8 次。
5. 对下一字节重复步骤 2~4，直到所有字节处理完成。
6. 计算结果即为 CRC。

发送 CRC 时必须先发送低字节，再发送高字节。例如 CRC 寄存器结果为 `0x0AD4`，实际发送顺序为：

```text
D4 0A
```

## 1.4 参数的写入与读出

所有参数均使用 16-bit 数据表示，通讯地址由参数组和参数序号确定。

### PA 组参数

```text
PA-n 的通讯地址 = 0x0000 + n
```

例如：

```text
PA-0 → 0x0000
PA-1 → 0x0001
PA-5 → 0x0005
```

### P3 组参数

```text
P3-n 的通讯地址 = 0x0100 + n
```

例如：

```text
P3-0  → 0x0100
P3-15 → 0x010F
```

### P4 组参数

```text
P4-n 的通讯地址 = 0x0200 + n
```

例如：

```text
P4-0  → 0x0200
P4-15 → 0x020F
```

### 参数数据格式

- 参数必须按十进制整数读写。
- 面板或手册中带小数点的参数，通讯值会按规定放大后传输。
- 二进制显示的参数，通讯时使用其对应的十进制整数。

| PA 参数序号 | 面板显示值 | 通讯操作值 | 转换方式 |
|---:|---:|---:|---|
| 1 | `315` | `315` | 不变 |
| 63 | `1.00` | `100` | 放大 100 倍 |
| 57 | `0100`（二进制） | `4`（十进制） | 二进制转十进制 |

## 1.5 状态量监视

状态量可通过 RS-485 读取，但不能写入。每项状态量使用 16-bit 数据保存；带小数的状态值按规定放大 10 倍或 100 倍。

| 地址 | 状态内容 |
|---:|---|
| `0x1000` | 电机转速 |
| `0x1001` | 当前位置，脉冲，低 16 位 |
| `0x1002` | 当前位置，脉冲，高 16 位 |
| `0x1003` | 位置指令，脉冲，低 16 位 |
| `0x1004` | 位置指令，脉冲，高 16 位 |
| `0x1005` | 位置偏差，低 16 位 |
| `0x1006` | 位置偏差，高 16 位 |
| `0x1007` | 电机转矩 |
| `0x1008` | 电机电流 |
| `0x1009` | 当前控制方式 |
| `0x100A` | 当前温度 |
| `0x100B` | 速度指令 |
| `0x100C` | 转矩指令 |
| `0x100D` | 一转中转子绝对位置，低 16 位 |
| `0x100E` | 一转中转子绝对位置，高 16 位 |
| `0x100F` | 输入端子状态 |
| `0x1010` | 输出端子状态 |
| `0x1011` | 编码器输入信号 |
| `0x1012` | 主电路母线电压值 |
| `0x1013` | 报警代码 |
| `0x1014` | 逻辑芯片版本号 |
| `0x1015` | 继电器吸合状态 |
| `0x1016` | 运行状态 |
| `0x1017` | 外部电压状态 |
| `0x1018` | 绝对位置值 bit `15~0` |
| `0x1019` | 绝对位置值 bit `31~16` |
| `0x101A` | 绝对位置值 bit `47~32` |
| `0x101B` | 绝对位置值 bit `63~48` |

### `0x1016` 运行状态定义

| 值 | 状态 |
|---:|---|
| `0` | 主电路未充电 |
| `1` | 主电路已充电，但伺服未使能 |
| `2` | 伺服存在报警 |
| `3` | 主电路已充电，伺服正在运行 |

### 64-bit 绝对位置拼接

```text
absolute_position =
    reg_1018
  | (reg_1019 << 16)
  | (reg_101A << 32)
  | (reg_101B << 48)
```

## 1.6 参数暂存及暂存地址

为了避免运行中频繁写 EEPROM，驱动器提供参数暂存地址：

```text
PA 暂存地址 = PA 保存地址 + 0x0080
```

写入暂存地址后：

- 参数立即生效。
- 参数不会保存到 EEPROM。
- 驱动器重新上电后恢复初始值。

示例：

| 参数用途 | 保存地址 | 暂存地址 |
|---|---:|---:|
| 正向转矩限制 | `0x0022` | `0x00A2` |
| 反向转矩限制 | `0x0023` | `0x00A3` |

## 2. 开发注意事项

1. 默认配置使用 `9600, 8N2`，驱动器和 STM32 UART 必须一致。
2. Modbus CRC 发送顺序是低字节在前、高字节在后。
3. 读写参数地址按参数编号换算，不要把 PA-1 误认为地址 `0x0000`；正确关系是 PA-0 → `0x0000`。
4. 位置、当前位置、绝对位置等多字节数据必须按低字到高字组合。
5. 带小数或二进制显示的参数不能直接把面板值原样写入通讯帧。
6. 运行时频繁变化的 PA 参数应使用暂存地址，避免反复写入 EEPROM。
7. 商家资料第 6 页的 PA 地址大表存在部分排版/录入不一致，程序应优先采用前文地址公式 `PA-n = 0x0000+n`。
8. `0x1015~0x101B` 是本资料新增的状态寄存器，使用前建议在目标驱动器上读取验证，以排除固件差异。
