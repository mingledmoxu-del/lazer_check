# v3.7.7 限位边界反馈容差

现场日志显示：17:10:03 起，回零状态为完成（7），DI0有效，转速0，参考编码器为−43946；实际编码器为−43952到−43956，角度反馈35.004°～35.007°。同时保护原因变为范围错误（2），停止待确认标记持续出现。这是+35°边界上的数个编码器count变化触发了严格软范围检查，反复进入停止，造成回水平被忙状态拦截；不是搜索总行程45°耗尽。

修复：仅双限位模式的实际角度反馈边界检查增加50毫度（0.05°）容差，并允许在此反馈容差内向严格软范围内定位。目标角度仍必须在−29°～+35°内；传感器阻挡朝限位方向的运动、通信/报警/单位异常、停止确认和其他保护保持有效。超过反馈容差仍触发范围停机。旧单限位模式不增加此容差。
