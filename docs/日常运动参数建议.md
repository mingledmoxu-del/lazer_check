# 日常运动参数建议（输出轴）

适用当前两轴P100S、50:1减速器和配套v3.5固件/SDK。下面用于保守调试和日常配置提示，尚未经本机构满负载实机验收，不能作为已认证的安全速度或机械极限。更换负载、传动或驱动器参数后需重新验证。

## 建议填写范围

所有角度、速度和加速度均为减速器输出轴单位，两轴都按下面的约束配置；电机2没有软范围不代表可无限提高速度。

| 参数 | 日常建议填写范围/设置 | 首次调试或故障后起始值 |
| --- | --- | --- |
| 最大速度 `max_speed` | 0.5～1.5 °/s | **0.5 °/s** |
| 最大加速度 `max_accel` | 1～3 °/s² | **1 °/s²** |
| 跟随误差阈值 `max_error` | 保持0.75°，不作为提速调节项 | **0.75°** |
| 终点容差 `tolerance` | 保持0.3° | **0.3°** |
| 控制周期 `cycle_ms` | 配套新固件保持100 ms | **100 ms** |

速度0.5°/s约为输出轴0.083 rpm、电机4.17 rpm；1.5°/s约为输出轴0.25 rpm、电机12.5 rpm。实际电机指令按整数rpm量化，极低速度也可能存在量化和爬行，建议区间的下端不是硬性最低速度。

这张表是建议工作区间，不是新增的API硬限制，也不是区间内任意速度/加速度组合都已验证可用。SDK不传参数时仍为1.5°/s、3°/s²；首次调试、未排除跟随误差故障时，应显式传入0.5和1，不依赖默认值。此次只补文档提示，没有自动下发或修改设备参数。

## 建议调用

先建立真实参考、确认停稳及路径安全；日常业务接口要求电机1已在水平0°、首点与两轴当前位置一致。

```python
# points 为原始轨迹点；本接口按相同的上限重新安排时间并上传。
ready = motors.prepare_business_trajectory(
    points,
    max_speed=0.5,
    max_accel=1.0,
    max_error=0.75,
    tolerance=0.3,
    cycle_ms=100,
)
# 这里只准备，不自动启动；现场确认后另行调用：
# motors.start_trajectory(ready.session)
```

高级接口 `prepare_trajectory()` 不自动放慢原始点；点的时间若不满足上述约束会拒绝，需要先延长时间或用 `app.trajectory.business_trajectory()` 重新规划。重规划总时长仍不能超过600秒。

## 如何逐步提高

1. 首先用0.5°/s、1°/s²在远离边界的位置做小幅测试，验证两轴方向、实际角度和停止功能。SON接上就自行转动的问题必须先处理，不应进入业务试跑。
2. 在预期负载下完整走业务路径，检查往返、换向和多圈重复运行的目标/实际角度、两轴误差及控制周期。低速仍有误差故障时先排查原因，不继续提速。
3. 保持加速度1°/s²，速度逐级尝试0.5→1.0→1.5°/s；每次只改一项并重新检查完整路径。速度验证通过后，确有需要再逐级尝试加速度1→2→3°/s²。
4. 出现故障7、持续误差增大、异常振动或终点不收敛，停止测试，退回已验证的参数并处理原因。不要通过放宽0.75°阈值来通过验收。清除旧故障和重新准备的步骤见[故障处理与恢复API](故障处理与恢复API.md)。

在当前跟随问题未排除前，不建议超过1.5°/s或3°/s²。超过本建议区间应由现场调试人员根据负载、驱动响应、停止距离和机械结构单独验证；接口允许输入不等于机构适合运行。

## 位置范围和驱动器参数

- 电机1固定物理水平坐标−35°～+35°。普通调试路径建议至少离边界3°，即目标尽量在−32°～+32°；这是额外的调试余量，不替代实际制动距离检查或代码中的路径检查。
- 电机2可不设软范围，但仍须确认线缆、机械干涉及允许旋转圈数，并建立有效参考。
- `set_motion_profile()` 的 `accel_ms/decel_ms/s_curve_ms` 是驱动器时间参数，不能把上表的1或3直接填进去。驱动器参数保留现场已确认设置；不要为了匹配此表而自动改PA40/PA41/PA42。需要调整时停稳、读取原值、按手册调试并读回验证。
- 跟随误差阈值不是保证实际误差永远不超过该数值的机械边界；采样、执行和停止过程仍有延迟。

## 接口允许范围，仅供区分

| 参数 | 接口数据范围 | 解释 |
| --- | --- | --- |
| `max_speed` | 0.001～60 °/s | 不是日常建议速度 |
| `max_accel` | 0.001～120 °/s² | 不是已验证的安全加速度 |
| `max_error` | 0.5～10° | 不应为消除报警而调大 |
| `tolerance` | 0.05～1°，且小于`max_error` | 按业务精度验证 |
| `cycle_ms` | 50～500 ms | 周期越短不代表实际总线一定更快 |

本文只规定文档中的建议。若同事平台希望强制限制日常输入，应在其日常配置页面采用上面的建议区间，并保留专业调试入口；当前SDK和固件的协议范围不变。
