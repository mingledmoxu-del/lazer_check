# v3.6 电机1双限位标定与可选方向回零

继续使用原 HYKJN1002 H743 板和 `LightCheck` 工程，UART1 上位机、UART3 RS485 电机总线不变。`LightCheck_F407` 仅保留为备用，不同步本次功能。

## 输入和实测角度

| 电机1限位器 | 板上 DI | MCU | 角度 |
| --- | --- | --- | --- |
| 接近水平的一只 | DI2 | PF3 | 用户实测，初始留空，不能默认0° |
| 抬头极限的一只 | DI0 | PF5 | 用户实测，初始留空，不能默认+25° |

输入使用原板隔离电路，外部传感器接板上 DI 端子，不直连 MCU。两路共用同一触发极性，可选择高或低；现有资料中的 NPN/Light-ON 接法通常遮挡后 MCU 为高，但必须根据实际 raw 输入确认。若两只传感器电平逻辑相反，先统一接线逻辑，本版不支持分别设置极性。

角度以真实水平0°、抬头为正。两个数填写**低速接近、触发后实际停稳姿态的实测角度**。软件通过 RS485 获取停稳后的编码器，不是触发瞬间的硬件位置锁存；速度、减速和触发位置变化会影响重复精度。采用一致的低速接近条件实测，限位安装在机械硬极限之前并留出停机余量。

本版保留电机1原有 −35°～+35°固定范围；实测角度超出范围会被拒绝。需要扩大机械行程时另行确认，不自动放宽。

## 上位机操作

启动 `app/start_simple.bat`，打开“位置反馈 / 限位 / 软行程 / 回零调试”，进入“电机1双限位”页。

1. 驱动器 SON 关闭时先观察 DI0～DI5 的 raw 变化，确认 DI2/DI0 对应关系和触发电平。启用自动刷新可持续看输入。
2. 选择正向是否抬头。这里的“正向”指驱动器原始命令正向：若原始正转使机构低头，选“负向抬头”。搜索方向始终是原始命令方向；正常角度定位和轨迹则自动转换成抬头为正的物理坐标。
3. 填写两个实测角度，应用双限位配置。角度可以暂留空，仅用于输入观察和触发停机；两角度都有效才允许自动搜索。读取实际配置确认下发结果。配置会使旧参考及旧轨迹失效，保存于 STM32 RAM，掉电后需重新应用。
4. 选择“正向”或“负向”，设置低速、行程预算和超时，再点击“按所选方向寻找限位并标定”。默认0.3°/秒、40°预算、120秒超时，速度上限1°/秒。默认速度120秒最多约36°，距离较远可能先超时，需要按真实距离调整。
5. 触发 DI2 或 DI0 后停机，连续两次确认实际转速为0，且同一限位仍触发、反馈单位有效，才建立该限位实测角度参考。页面可读取“最近触发：水平侧/抬头极限”。**完成后停在该限位，不自动反向、不自动走到0°。**
6. 若两路都未触发且失败、需要中止，按停止；不自动重试。从已触发的传感器上启动搜索会被拒绝。已建立可信参考时，可用小幅物理角度命令离开限位；水平侧禁止继续往负角度走，抬头侧禁止继续往正角度走。
7. 只有确认标定有效且从当前限位到0°的行程可达后，才点击“已标定后移动到真实0°”。此按钮使用输出轴0.05 rpm（0.3°/秒），单独确认后移动。如果水平侧实测为正角度，例如+2°且它是负端限位，0°在该端之外，程序会拒绝朝限位内继续走；应调整限位安装/可用行程，不能用错误参考绕过。

方向未知时不要使用普通大步长定位。若先测试原始正/负搜索，应保持低速、短行程预算、手边可停机，并核对实际方向后重新应用角度方向配置。软件不会自动推断电机接线或自动试两个方向。

## 触发、故障和兼容性

双限位模式默认关闭，必须显式应用。启用后，无论由搜索还是普通角度运动触发任一限位，均先停止再按其角度建立参考。瞬时触发后又离开限位、两路同时触发、参考角度未测量、反馈单位变化、通信/驱动器异常，均不建立有效参考。搜索还有通信续期、总超时、总行程、方向和无进展检查；断联或停止后不会自动恢复运动。

双轴轨迹遇到任一限位会先停止两轴，随后才能处理电机1标定，旧轨迹作废。电机2逻辑不变，不能把电机1占用的 DI2、DI0 同时分配给电机2保护。

双限位模式下，旧“人工确认+25°”、旧单原点回零、旧保护配置以及原始脉冲/速度/通用参数运动入口被拒绝，防止绕开角度方向或把限位误设成+25°。读取状态、停止、物理角度相对定位、双轴轨迹仍可用。SDK 可调用 `configure_axis1_limits(enabled=False, ...)` 关闭双限位并使参考失效，再显式重新标定；关闭不是故障恢复或继续运动。

## SDK 示例

```python
# 下列 2°、28°仅用于展示参数格式，必须替换成自己的实测值。
motors.configure_axis1_limits(
    horizontal_channel=2, raised_channel=0,
    active_high=True, positive_is_up=False,
    horizontal_deg=2.0, raised_deg=28.0,
)
motors.start_axis1_limit_homing(-1, speed_deg_s=0.3,
                               max_travel_deg=20, timeout_s=90)
feedback = motors.wait_homing(1, timeout=95)
print(motors.get_axis1_limits())  # last_hit: horizontal / raised
print(feedback.output_angle_deg)
# 不会自动发定位命令。只有确认0°在可达行程内，才显式调用：
# motors.move_to_angle(1, 0, speed_rpm=0.05)
```

新增协议：0x26 配置（key 0x444C，14字节 `>BBBBbBii`：启用、水平通道、抬头通道、触发高、角度方向±1、角度有效位、两个毫度角）；0x27读取（16字节，前14字节同配置，附最近触发0/1/2、待处理限位0/1/2）；0x28搜索（key 0x4448，13字节 `>biii`：原始方向±1、速度毫度/秒、预算毫度、超时毫秒）。仅电机1支持，所有新帧校验长度和key。反馈0x20长度不变，phase=7表示参考建立成功；当前角度不必为0°。
