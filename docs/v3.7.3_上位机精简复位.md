# v3.7.3 上位机精简操作

本版仅修改上位机，继续配套 v3.7.2 H743 网口固件。板端地址仍为 `192.168.10.50:5000`。

固定实测配置：DI0 高电平触发为 +37°，DI2 高电平触发为 −29°，原始反向抬头。界面不再要求选择触发电平、方向或输入实测角度。

## 日常操作

1. 上电前把头部尽量摆平，确保 DI0、DI2 都未触发。板子、驱动器上电后连接上位机网口。
2. 主窗口点击“① 复位到 +37°”，确认后自动停止当前动作、下发固定配置并反向抬头。默认搜索速度 0.5°/秒，行程预算 45°，超时 120 秒。
3. DI0 触发后停止，确认停稳才建立 +37°角度参考，界面显示完成。它是机构复位动作，不是给 STM32 断电或复位。
4. 需要水平姿态时点击“② 电机1移到水平0°”。电机2仍保留“确认当前位置为0°”，两轴准备就绪后可进入业务轨迹。

复位过程中可随时点停止。复位结束保持 +37°，不会自动回水平。板子掉电或复位后，重新执行机构复位。窗口中的位置与限位状态可勾选刷新；打开窗口本身不下发运动。

## 界面清理

删除旧 +25°人工参考、旧单限位回零、双向通用搜索、手动 DI 映射/电平/方向/角度配置、软范围编辑及配置草稿导入导出。主窗口也移除了重复的电机2上电参数查询快捷按钮，参数查询仍在高级调试中。

保留复位到 +37°、水平0°定位、停止、反馈状态、电机2参考、业务轨迹和运动/参数调试。SDK和固件协议保持兼容；界面不再提供旧流程。

运行 `app/start_simple.bat`。发布包 `output/upper-computer/v3.7.3-fixed-reset/upper-computer-source.zip` 解压后也可使用同一启动脚本。无需重烧已使用的 v3.7.2 固件。

验证：156 项 Python 测试通过；实际构造 Tkinter 界面，核对旧按钮与可编辑限位字段已删除、主窗口复位入口下发固定高电平配置和 DI0 专用搜索，打开窗口不产生运动。未进行电机实测。
