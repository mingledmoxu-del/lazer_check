# v3.7.2 实测双限位与反向抬头回零

本版继续使用 H743 主网口 CN2，TCP 地址仍为 `192.168.10.50:5000`，保留 v3.7.1 的断线停机与诊断重连处理。

用户实测：原始命令正向使头部向下，反向使头部向上。DI2 为 −29°，DI0 为 +37°，真实水平为 0°。双限位模式的固定软范围更新为 −29°～+37°；未启用双限位的旧单限位模式仍使用旧范围。F407 备用工程未修改。

## 使用方法

1. 烧录 `output/firmware/v3.7.2-measured-homing-h7/LightCheck.hex`，重启上位机 `app/start_simple.bat`。
2. 上电前尽量把头部摆到接近水平，保证两个限位均未触发。接近水平只是搜索起始条件，不会直接被当成准确 0°；上电、连接和打开窗口均不自动运动。
3. 连接网口后，点击主窗口“① 电机1双限位回零”。先确认 DI0、DI2 的实际触发电平，再选择高电平或低电平触发。
4. 点击“反向抬头回零（DI0 / +37°）”。按钮先停止当前动作，再下发 DI2=−29°、DI0=+37°、反向抬头配置，读回配置，随后发起原始反向搜索。配置下发失败会取消后续搜索。
5. DI0 触发后发出停止命令，连续两次反馈停稳且该限位仍触发、编码器单位未变化，才建立 +37°参考。当前位置显示 +37°，保持不再自动移动。
6. 需要回水平时，再点击“已标定后移动到真实 0°”。该动作按物理负角度运动，转换为电机原始正向命令。

默认搜索速度 0.5°/秒，受驱动器整数转速量化影响实际约 0.48°/秒；从 0° 到 +37°约 77 秒。搜索行程预算 45°，超时 120 秒，因此适用于从接近水平位置出发。预算不是对初始姿态的校验；从 −29°附近出发可能在找到 DI0 前先超预算停机。

限位参考使用停止后的编码器位置，存在输入去抖、通信和减速延迟，不是触发瞬间的硬件位置锁存。实测角度应对应相同低速下的停稳姿态，首次低速验证后可复核测量。

DI0、DI2 的配置和参考仍只存 RAM。每次复位/掉电后重新点击专用回零按钮即可重新配置并搜索。该按钮覆盖页面中的通道、方向和角度草稿，固定使用这次实测配置；速度、预算、超时及触发电平取自页面。通用“按所选方向寻找限位并标定”仍支持两方向，任一限位可建立其对应参考。

## 异常处理与协议

专用 DI0 搜索时若先触发 DI2，会停机并以传感器错误结束，不报告回零成功。两限位同时触发、启动前限位已触发、反馈异常、断线、心跳失效、超时、超行程均不自动重试。无参考时禁止普通角度运动。

`0x28` 的原有 `parameter=0x4448` 保留，表示任一限位搜索。新增 `parameter=0x4449` 表示专用抬头回零，数据仍为 13 字节 `>biii`。固件检查方向必须为 −1，配置必须为 DI2/DI0、−29°/+37°、反向抬头，且仅抬头限位可成功完成。旧固件会拒绝新键，需配套升级。

SDK：

```python
# active_high 按实际回路设置；调用后由 SDK 续期搜索心跳。
controller.home_axis1_raised(active_high=True)
feedback = controller.wait_homing(1)
# 成功时 output_angle_deg == 37；需要时另行发出移动到水平的命令。
```

验证：10 组 C 主机回归测试、Python 测试、H743 网口 Debug 编译和 GUI 构造检查。新增回归覆盖 +37°标定、反向抬头、正向回水平、错误限位停机、DI2=−29°参考、新协议键与配置失败取消搜索。本版未替用户烧录，尚需机械实测。
