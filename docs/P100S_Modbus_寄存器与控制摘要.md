# P100S 伺服驱动器：Modbus 与控制摘要

> 来源：`31.P100S-Series-Servo-Manual-Book.pdf`
>
> 本文件只整理 LightCheck 与 P100S 通讯、参数配置和运动控制相关的内容，不替代原厂手册。首次上电和带负载运行前，应先脱离负载进行测试，并保留急停措施。

## 1. 通讯基本配置

接口为 RS-485，协议为 Modbus RTU。

| 项目 | 参数 | 默认值/说明 |
|---|---|---|
| 从站地址 | PA-71 | `1`，范围 `1~254` |
| 波特率 | PA-72 | `96` 表示 `9600 baud` |
| 帧格式 | PA-73 | `0: 8,N,2`；`1: 8,E,1`；`2: 8,O,1` |
| 建议配置 | - | 默认 `9600, 8N2, Modbus RTU` |

RS-485 端子：CN3/CN4 中 `4 = RS485-`，`5 = RS485+`。实际接线时确认控制器 A/B 命名与驱动器正负端对应关系。

## 2. Modbus 帧格式

### 2.1 通用帧

```text
[ADR] [CMD] [DATA ...] [CRC Low] [CRC High]
```

- `ADR`：从站地址，1 byte。
- `CMD`：命令码，1 byte。
- 数据按 16 bit word 传输，高字节在前。
- CRC 为 Modbus CRC-16，发送时低字节在前、高字节在后。
- 帧与帧之间至少间隔 3.5 个字符时间。

### 2.2 读 N 个 16-bit word：功能码 `0x03`

请求：

```text
[ADR] 03 [起始地址 High] [起始地址 Low] [数量 High] [数量 Low] [CRC Lo] [CRC Hi]
```

响应：

```text
[ADR] 03 [字节数] [数据 High] [数据 Low] ... [CRC Lo] [CRC Hi]
```

示例：从站 `1`，从地址 `0x0005` 开始连续读取 2 个参数：

```text
请求：01 03 00 05 00 02 D4 0A
```

### 2.3 写 1 个 16-bit 参数：功能码 `0x06`

请求/正常响应格式相同：

```text
[ADR] 06 [地址 High] [地址 Low] [数据 High] [数据 Low] [CRC Lo] [CRC Hi]
```

### 2.4 CRC-16

- 初值：`0xFFFF`
- 多项式：`0xA001`
- 对 ADR、CMD 和全部数据字节计算，不包含 CRC 本身。
- 发送顺序：CRC Low，再 CRC High。

```c
uint16_t crc16_modbus(const uint8_t *data, size_t len);
```

## 3. 参数寄存器地址换算

每个参数占 1 个 16-bit word，通讯值为十进制整数。参数显示带小数时，通讯值按手册规定放大 10 倍或 100 倍。

| 参数组 | 地址公式 | 示例 |
|---|---|---|
| PA | `0x0000 + 参数编号` | PA-0 → `0x0000`；PA-5 → `0x0005` |
| P3 | `0x0100 + 参数编号` | P3-0 → `0x0100`；P3-15 → `0x010F` |
| P4 | `0x0200 + 参数编号` | P4-0 → `0x0200`；P4-2 → `0x0202` |

### 3.1 PA 参数地址示例

| 参数 | 通讯地址 |
|---|---:|
| PA-4 控制方式 | `0x0004` |
| PA-11 每转指令脉冲数 | `0x000B` |
| PA-12 电子齿轮分子 | `0x000C` |
| PA-13 电子齿轮分母 | `0x000D` |
| PA-14 脉冲输入方式 | `0x000E` |
| PA-15 脉冲方向取反 | `0x000F` |
| PA-19 位置指令平滑滤波 | `0x0013` |
| PA-22 内外部速度指令选择 | `0x0016` |
| PA-24~PA-27 内部速度 1~4 | `0x0018~0x001B` |
| PA-40 加速时间 | `0x0028` |
| PA-41 减速时间 | `0x0029` |
| PA-71~PA-73 通讯配置 | `0x0047~0x0049` |

> 注意：PA 编号是参数编号，不是从 1 开始的 Modbus 地址；PA-n 的地址就是 `0x0000+n`。

## 4. 控制方式与关键参数

### 4.1 位置控制

| 参数 | 作用 | 范围/建议 |
|---|---|---|
| PA-4 | 控制方式选择 | `0`：位置控制 |
| PA-11 | 电机转 1 圈的指令脉冲数 | 默认 `10000` |
| PA-12 | 电子齿轮第一分子 | 与 PA-13 配合 |
| PA-13 | 电子齿轮分母 | 默认 `10000` |
| PA-14 | 脉冲输入方式 | `0` 脉冲+方向；其他模式见手册 |
| PA-15 | 脉冲方向取反 | `0/1` |
| PA-19 | 位置指令平滑滤波 | `0~1000 × 0.1 ms` |
| PA-16 | 定位完成范围 | 单位：脉冲 |
| PA-17 | 位置超差检测范围 | 单位：`100 脉冲` |

外部脉冲输入最大频率：差分输出 500 kpps，开集电极 200 kpps。

### 4.2 速度控制

| 参数 | 作用 | 默认值 |
|---|---|---:|
| PA-4 | 控制方式选择 | `1`：速度控制 |
| PA-22 | 内部/外部速度指令选择 | `0~5` |
| PA-24~PA-27 | 内部速度 1~4 | `100/500/1000/2000 r/min` |
| PA-40 | 加速时间 | `100 ms` |
| PA-41 | 减速时间 | `100 ms` |
| PA-43 | 模拟速度指令增益 | `300 r/min/V` |
| PA-75 | 零速检测点 | `10 r/min` |
| PA-76 | 速度一致设定值 | `10 r/min` |

### 4.3 数字输入/输出功能

| 参数 | 默认功能 |
|---|---|
| P3-0 | DI1：伺服使能 |
| P3-1 | DI2：报警清除 |
| P3-2 | DI3：正向驱动禁止 |
| P3-3 | DI4：反向驱动禁止 |
| P3-20 | DO1 功能 |
| P3-21 | DO2 功能 |
| P3-22 | DO3：定位完成 |
| P3-23 | DO4：电磁制动 |

P3 参数地址为 `0x0100 + 编号`。DI/DO 功能可以通过对应 P3 参数重新映射。

## 5. 内部位置寄存器（Pr 模式）

内部位置模式使用 8 组位置命令。每组包含：圈数、脉冲数、移动速度。

| 位置点 | 圈数参数 | 脉冲参数 | 速度参数 |
|---|---|---|---|
| P1 | P4-2 | P4-3 | P4-4 |
| P2 | P4-5 | P4-6 | P4-7 |
| P3 | P4-8 | P4-9 | P4-10 |
| P4 | P4-11 | P4-12 | P4-13 |
| P5 | P4-14 | P4-15 | P4-16 |
| P6 | P4-17 | P4-18 | P4-19 |
| P7 | P4-20 | P4-21 | P4-22 |
| P8 | P4-23 | P4-24 | P4-25 |

对应通讯地址为 `0x0200 + P4 参数编号`。例如：

- P1 圈数 P4-2 → `0x0202`
- P1 脉冲 P4-3 → `0x0203`
- P1 速度 P4-4 → `0x0204`

POS0、POS1、POS2 选择 8 组位置，CTRG 的 0→1 上升沿触发运行。圈数范围为 `-30000~30000`；脉冲单位为每转最大指令脉冲数；速度单位为 r/min。

## 6. 状态监控寄存器

状态只能读，不能写；每项为 16-bit 数据。32-bit 位置量需要按低字、高字组合。

| 地址 | 内容 |
|---:|---|
| `0x1000` | 电机速度 |
| `0x1001` / `0x1002` | 当前位置低字 / 高字 |
| `0x1003` / `0x1004` | 位置指令低字 / 高字 |
| `0x1005` / `0x1006` | 位置偏差低字 / 高字 |
| `0x1007` | 电机转矩 |
| `0x1008` | 电机电流 |
| `0x1009` | 当前控制方式 |
| `0x100A` | 温度 |
| `0x100B` | 速度指令 |
| `0x100C` | 转矩指令 |
| `0x100D` / `0x100E` | 转子单圈绝对位置低字 / 高字 |
| `0x100F` | 输入端子状态 |
| `0x1010` | 输出端子状态 |
| `0x1011` | 编码器输入信号 |
| `0x1012` | 主回路母线电压 |
| `0x1013` | 报警码 |
| `0x1014` | 逻辑芯片版本号 |

读取状态使用功能码 `0x03`，起始地址直接使用上表地址。

## 7. 临时参数地址

PA 参数的临时地址 = 普通保存地址 + `0x0080`。

- 普通地址 `0x0022` → 临时地址 `0x00A2`
- 普通地址 `0x0023` → 临时地址 `0x00A3`

写入临时地址会立即生效，但掉电后恢复原值；需要保存到 EEPROM 的参数才使用普通地址。运行过程中频繁变化的参数应优先使用临时地址，以减少 EEPROM 写入。

## 8. 推荐的软件实现流程

1. 初始化 UART：`9600, 8N2`，RS-485 收发方向由 `RS485_RE` 控制。
2. 发送前切换为发送，发送完整 Modbus 帧。
3. 等待发送完成后切换为接收，等待从站响应。
4. 校验从站地址、功能码、数据长度和 CRC。
5. 上电后先读取 `0x1013` 报警码和关键状态。
6. 初始化时写入必要的 PA/P3/P4 参数，并按需要重新上电使部分参数生效。
7. 运行中周期读取速度、位置、偏差、报警和输入输出状态。
8. 发生异常时停止发运动命令，读取报警码并保留急停控制。

## 9. 重要注意事项

- P100S 的通讯参数表说明了寄存器地址规则，但实际使用前仍应核对驱动器型号和固件版本。
- 32-bit 位置量必须把两个 16-bit 寄存器正确拼接，并确认有符号数处理方式。
- 带小数的参数通讯值可能已被放大 10 倍或 100 倍，不能直接按面板显示值写入。
- 先空载测试，再连接机械负载；首次调试必须确保急停可用。
- RS-485 A/B 极性、终端电阻、信号地和屏蔽应按实际控制器接线要求确认。
