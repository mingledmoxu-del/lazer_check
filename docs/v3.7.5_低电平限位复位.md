# v3.7.5 低电平限位复位

现场分别触发验证：DI0 触发时 MCU 读到 DI0=0、DI2=1；DI2 触发时读到 DI0=1、DI2=0。两只限位均未触发时为1。因此本版上位机的固定复位配置改为低电平触发（active_high=False）。旧版“高电平触发”说明不再适用于这套实测接线。

角度与方向不变：DI0=+37°，DI2=−29°，原始反向抬头。专用复位仍先停止，再下发完整双限位配置，读回配置，随后启动 DI0 专用搜索。DI0 触发后停稳标定为+37°；搜索中意外碰到 DI2 会停机失败，不跳过保护。

## 操作

1. 关闭旧上位机，重新运行 `app/start_simple.bat`，确认标题为 v3.7.5。
2. 将头部摆回接近水平，释放 DI0、DI2，让两路都处于未触发状态（原始电平均为1）。
3. 连接网口后点击“① 复位到 +37°”，确认后自动下发低电平配置并反向抬头。读回配置应显示低电平触发。
4. DI0 触发（raw=0）后停止，确认停稳才标定为+37°。需要水平姿态时再点击移动到0°。

继续配套 v3.7.2 H743 网口固件，无需重烧。仅重启上位机不会修改板端仍在 RAM 中的旧高电平配置；点击复位后才会下发新配置，因此在这一步之前读回仍可能显示高电平。

默认搜索0.5°/秒、预算45°、超时120秒，适用于从接近水平处出发。低电平触发不能保证检测断线，软件停止仍有输入、通信和减速延迟。

验证：157项Python测试、10组C主机回归，新增实际低电平配置下的DI0触发+37°标定及错误DI2触发停机验证；Tkinter界面构造与固定配置帧检查。未替用户执行运动，现场仍需低速验证。
