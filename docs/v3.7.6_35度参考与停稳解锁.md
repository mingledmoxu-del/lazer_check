# v3.7.6：+35°参考与停稳解锁

抬头限位 DI0 根据最新测量改为 +35°，DI2 保持 −29°。两路保持 MCU 低电平触发（未触发1、触发0），原始反向抬头。双限位固定范围更新为 −29°～+35°，固件专用回零校验、上位机复位配置、SDK和界面提示同步更新。

本版需要固件和上位机一起更新：旧 v3.7.2 固件的专用回零检查固定要求 +37°，无法接受新版 +35°配置。烧录 `output/firmware/v3.7.6-35deg-stop-release-h7/LightCheck.hex`，重启 `app/start_simple.bat`，确认标题为 v3.7.6。

## 停稳后继续回水平

收到实际零速的停止确认后，统一清除上位机的自动运动、定角运动占用、回零标记、监测等待和诊断占用。回零完成也使用统一清理，避免遗留活动轴状态。回零后的只读配置反馈改为后台查询，不阻止下一个操作；下一操作可取消尚未发送的只读查询。业务准备期间暂停复位窗口轮询，避免两者争用。

保留未停稳拦截：非零速、板端仍在停止确认或回零阶段时不会以回零成功解锁。不通过清除角度参考、改传感器状态或跳过固件保护来解除忙状态。

日常流程：头部接近水平且两个限位未触发 → 连接 → 复位到+35° → DI0触发、停稳并显示+35°参考建立完成 → 移到水平0°。如果在找到DI0前手动停止，尚未建立有效角度参考，必须重新完成限位复位，不能直接按坐标移动到0°。

## 验证

160项Python测试、10组C主机测试、H743网口Debug编译通过。新增覆盖停止确认清理全部占用、非零速继续保持忙、后台读回不阻止水平操作。GUI模拟验证+35°回零完成后可以进入回水平流程。固件HEX/BIN一致性及启动向量检查通过。尚未电机实测。
