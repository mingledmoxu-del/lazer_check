# v3.7.8 可选复位速度

仅更新上位机，继续配套 v3.7.7 固件，无需重烧。

主窗口点击复位入口后先打开复位窗口，不立即发起动作。在“复位速度（输出轴 °/秒）”选择 0.5、0.6、0.8 或 1.0，再点击窗口里的“复位到+35°”。确认框显示本次速度和输出轴rpm换算，通信日志记录选择值。默认0.5，修改仅作用于下一次复位，不会在运动中改速。

1°/秒约0.167输出轴rpm；受驱动器整数转速量化影响实际约0.96°/秒，从水平到35°约36秒。主窗口定角运动的rpm输入仍独立，不用于限位搜索。回水平速度保持原样。

固件限位搜索上限为1°/秒，本次没有提高该上限，也不改DI电平、限位角度、45°预算、120秒超时和边界保护。

验证：160项Python测试通过；GUI检查主窗口入口不自动运动、四档速度均进入实际搜索帧，仍保持先停稳、配置、读回、搜索的顺序。待现场验证。
