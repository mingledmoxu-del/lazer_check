# v3.8.2 速度设定除6

用户要求：输入速度除以6后作为实际输出轴rpm。复位和回水平的GUI输入、高层SDK的reset_axis1/reset_axis2/move_to_zero统一换算一次。

| 输入设定 | 实际输出轴rpm | 对应角速度 |
|---|---|---|
| 0.5 | 约0.0833 | 约0.5°/秒 |
| 默认0.6 | 0.1 | 0.6°/秒 |
| 1.5 | 0.25 | 1.5°/秒 |

输入范围仍为0.2～1.5。驱动器使用整数电机rpm，实际速度存在量化，例如0.5设定约得到输出0.08rpm/0.48°/秒，从水平到35°约73秒。

API为兼容调用保留参数名speed_rpm，但这些高层方法的参数从本版起表示设定值，内部除6。例：reset_axis1(speed_rpm=0.5)实际以约0.0833输出轴rpm运行。不要在调用前重复除6。低层move_to_angle/move_relative的speed_rpm仍表示真实输出轴rpm，不改变。

仅更新上位机/SDK，继续使用v3.8.1固件，无需重烧。参考保留、显式清参考、限位和停止保护不变。极慢的0.2设定首次从水平搜到35°可能超出120秒固件搜索超时，应使用默认0.6或0.5完成首次搜索。

验证：173项Python测试、GUI下发帧检查，确认复位与回水平只缩放一次。未进行电机实测。
