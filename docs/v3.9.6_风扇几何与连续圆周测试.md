# v3.9.6 风扇几何与连续圆周测试

## 固件与执行方式

**已有 H743 v3.9.4 固件无需修改或重烧。** 本版只更新上位机和离线轨迹生成代码，使用已有0x30～0x36连续轨迹协议。若现场是更旧固件，应先核对兼容性，不会自动降级到逐点停稳。

上位机根据风扇几何、转速和圈数计算一组带时间的双轴绝对角度，完整上传到板端RAM并校验；点击启动后，下位机按共同时间轴插补，连续更新两台驱动器速度。不是上位机每到一点发送一次定位，也不是每个离散点停车。上传完成只进入READY，必须单独启动；一次执行有限圈数，结束后统一收敛并停止。

连续轨迹缓存与六套逐点库是不同接口，本功能不覆盖库6或修改六套点位库内容。连续轨迹缓存一次只有一条，本页与原「两轴轨迹试验」共用同一传输和执行器，上传其他连续轨迹会替换当前连续草稿。测试不建立/清除参考、不改PA驱动器参数、不启动激光采集。

## 界面步骤

1. 启动 `app/start_simple.bat`，连接 `192.168.10.50:5000` 或串口，按原流程完成两轴真实参考并停稳。
2. 打开主界面「风扇几何 / 连续圆周测试」。默认模型台架：直径1.6m，距离2.5m，风扇中心高1.5m，激光出射点高0.77m，跟踪半径55%，风扇稳速转速3rpm，1圈64段，渐入/渐出各2s。
3. 选择模型或实机。选择实机时直径、距离、两者高度及原点修正会清空，必须输入实测值，不能把台架数据直接带到60～100m工况。其他输入也须按现场填写。
4. 点击「①生成/预览」。检查坐标、角度范围、首末点、点数、总时长及所需轴速度/加速度。生成仅在本地计算，不连接或运动。蓝圈为理想目标圈。
5. 核对真实参考及整个运动路径，勾选确认。点击「②定位起点（运动）」，使用旁边独立的实际轴rpm低速前往首点；确认框通过后实际运动。该动作不会自动开始画圆，也不会覆盖既有联动计时记录。等待起点定位完成。
6. 点击「③上传圆周（不运动）」。整条上传/校验后显示已预载，电机仍不运行。若板端拒绝范围、速度、参考或其他约束，先处理原因，不能忽略报错。
7. 点击「④开始连续画圆」，核对启动提示后运行。初期建议默认慢速模型；本页固定时间推进，不能跟上时按既有保护停止，不会自动延长风扇周期。红线为驱动器角度加理想几何换算出的平面轨迹，**不是相机实测光斑**。
8. 完成后填写本次目测抖动评级和备注，点击「导出轨迹/结果」。修改参数后重新生成、上传才能启动；完成、停止、断线后不会自动循环或重播。

本页和主界面停止均可停止当前任务；关闭本页也会取消其准备/运行。停止过程中仍等待已有板端停止确认。时间不明、通信超时或连接断开时不能声称实际停稳。继续保留硬件限位及原有故障保护。

## 参数含义

| 参数 | 含义 |
|---|---|
| 风扇直径m | 叶轮外径，单位米 |
| 跟踪半径% | 相对叶轮半径，55%表示跟踪 `直径/2×0.55` 的圆 |
| 稳速段风扇rpm | 模拟转子的转速，不是两台电机的输出轴转速；周期 `T=60/rpm` |
| 叶片数 | 本轮试验配置记录，不改变跟踪圆周期；不会把三叶片的通过间隔误作每转周期 |
| 距离Z m | 激光器坐标系正前方Z方向到风扇中心的距离，**不是斜距** |
| 风扇/激光高度 | 统一地面基准，激光高度填出射点的高度；相减得到中心高差 |
| 中心偏移X m | 从激光器看向前方，风扇中心向右为正 |
| 叶轮平面偏航/倾斜 | 默认0表示叶轮平面与X/Y平面平行；按下文旋转定义输入，不能直接套用不一致的现场角度符号 |
| 俯仰/水平原点修正 | 理想光线方向角到已建立电机参考角的加性偏移；本页不自动做标定 |
| 起始相位/方向 | 相位0在叶轮局部正下方，顺时针按从激光器看向正对叶轮定义 |
| 总圈数/每圈段数 | 总圈数包括渐入/渐出期间转过的角度；中间跨圈不停机；点数=`圈数×段数+1` |
| 渐入/渐出各秒 | 首尾沿圆周平滑提升/降低计划相位速度，不是每个离散点停车；填0则无计划渐变 |
| 控制周期ms | 下位机周期50～500ms，默认100ms；不同于上传离散点时间间隔。实际以板端通信/调度统计为准 |
| 最大轴速度/加速度 | 单位°/s、°/s²；轴rpm=`°/s÷6`，约束轨迹而不改变输入风扇周期 |
| 跟随保护误差/最终容差 | 现有固件连续跟随保护阈值最小0.5°；最终停车容差可填0.2°。最终容差不等于运动中始终保持±0.2° |

例如风扇12rpm就是5s/转，不是两台电机各转12rpm。两台电机的瞬时速度由尺寸、距离、姿态、半径和风扇相位共同决定，界面预览会显示离散角度轨迹的峰值需求。

## 轨迹模型

激光器出射点为坐标原点，X向右、Y向上、Z向前；理想俯仰/水平转轴正交且交于原点。风扇中心 `C=(X, 风扇高度−激光高度, Z)`。叶轮平面以偏航ψ及倾斜β定义正交基：

```text
u = (cosψ, 0, −sinψ)
v = (sinψ·sinβ, cosβ, cosψ·sinβ)
n = (sinψ·cosβ, −sinβ, cosψ·cosβ)
P(t) = C − r·sinφ(t)·u − r·cosφ(t)·v
pitch(t) = atan2(Py, sqrt(Px²+Pz²)) + pitch_origin
yaw(t)   = atan2(Px, Pz) + yaw_origin
```

角度换算为度，上传时量化到0.001°/1ms。空间平面的圆换算为两轴角度后，通常不是简单的两轴同幅正弦/余弦。真实转轴偏置、安装滚转角、出射点到转轴的距离及机构柔性不在该理想模型内；60～100m工况仍应实物标定，并用相机/靶纸检查真实光斑路线。

板端在有限角度点之间做线性插补，因此实际计划是理想圆的离散近似；段数过少会增加路径偏差。蓝圈只是理想几何参考，不能据此证明有限采样和实际机构已经画出精确圆。

渐变使用相位速度的 `3u²−2u³` 过渡，从静止升到输入风扇rpm，结束时反向过渡到静止。设渐变各R秒、总圈数N、周期T，则中间稳速持续 `N×T−R` 秒，总计划时长 `N×T+R`，整条路线正好N圈并回到首点。默认3rpm、1圈、R=2s，总计划22s，其中起止渐变共4s、中间稳速18s。该过渡经离散上传和现有插补近似执行，不是新增驱动器硬件S曲线模式。

开始/结束渐变阶段本身不与一个始终匀速的真实风扇锁相。这个版本是圆周运动能力测试，**没有读取真实叶轮相位或转速反馈**；正式跟踪同一真实叶片还需相位信号、启动对相和相位闭环方案。

## 现有固件边界

- 一次2～128点、点间隔至少50ms、总计划1～600s。默认1圈64段共65点；例如3圈可选每圈32段，共97点。不会为绕过容量自动降低采样密度或在圈间重复停止/上传。
- 电机1固定−29°～+35°，轨迹点还须保留1°余量。本地检查−28°～+34°，板端仍以实际保护配置和制动余量检查；电机2按实际参考/范围策略检查。
- 规划约束0.001～60°/s、0.001～120°/s²；现有固件跟随误差0.5～10°、最终容差0.05～1°且小于跟随误差。超过规划约束时拒绝生成，要求调整转速/渐变等参数，不自动改变周期。
- RS485仍依次读写两轴，没有改成硬同步伺服总线。50ms只是可配置下限，不能当作已达到的实测周期。
- 连续执行期间没有每段停稳等待；最后一圈结束仍使用既有末点收敛和组停止确认，因此总墙钟时间会长于设定轨迹时长。本版没有为了缩短最终停止时间改固件确认周期。
- 不自动增加PID、调整PA41/PA42、清故障、扩大软限位或降低保护标准。带载跟随能力、反向时抖动与移动采集质量仍需实测。

## 数据导出与判读

一次导出三个文件：

- `name.json`：运行参数、输入场景、实际上传角度时间点、上传/启动收发事件、初始定位记录、原始状态观测、误差统计、目测评级/备注、最终状态。
- `name.csv`：运行反馈观测表，包含主机相对发令时间、状态、板端轨迹进度、两轴角度/误差、最大调度间隔、本轮通信耗时、估算平面坐标/径向偏差/相位偏差。
- `name_trajectory.csv`：该次上传的 `time_s,axis1_deg,axis2_deg` 轨迹点。JSON同时保留当前草稿配置，避免之后编辑草稿混淆本次运行配置。

JSON主要阶段字段：`upload_elapsed_s`为BEGIN发出到SEAL应答；`start_ack_s`为START实际写出到其应答；`first_control_feedback_s`为首次看到非零计划进度的有效反馈；`planned_end_observed_s`为首次观察计划结束；`completion_tail_s`为该观察到最终DONE/FAULT/CANCELLED的时间；`wall_elapsed_s`为START实际写出到终态的总观测时间。它们不是可直接全部相加的互斥耗时。

圆周运行时状态请求最短间隔设为100ms，位置请求500ms，心跳仍按原协议续期，结束后恢复原周期。状态读取使用板端缓存，不增加RS485驱动器查询。实际观测间隔受链路和其他必要通信影响，不能把这些观测误当成独立、同时采样的高速传感器数据。最多保留10000条状态观测，超过部分计数但不继续占用内存。

反馈图的红线由两轴角度通过理想几何投到叶轮平面。径向/相位偏差是相对于**输入的理想圆周计划**估算，并非真实叶片相位误差；峰值和RMS是按收到的有效缓存观测统计，样本之间可能相关。没有光斑相机或机头振动传感器，不能据此宣称机械无振动。实际抖动请填写目测评级，必要时用带时码视频核对。完成或停止确认后再导出，避免文件I/O阻塞运动通信。
